# DevCenterPoint Technology Policy v1

## Default Frontend
- React
- TypeScript
- Vite
- Tailwind CSS

## Default Backend
- Laravel 13+
- PHP 8.3+

## Default Database
- PostgreSQL (preferred)
- MySQL (client compatibility)

## Cache & Queue
- Redis

## Realtime
- Laravel Reverb
- Pusher/Ably when required

## Hosting
- Cloudflare DNS
- VPS preferred
- cPanel only for low-budget client projects

## Version Control
- GitHub Organization

## Branch Strategy
- main = production
- develop = active development
- feature/* = features
- hotfix/* = urgent fixes

## Code Quality
- ESLint
- Prettier
- Laravel Pint
- Pull request review required
